# Інтернет-магазин чаю 'T-Lab'

## Команда
- Волинчук Павло
- Мадай Денис

## Опис
«T-Lab» — це спеціалізований інтернет-магазин якісного листового чаю. Призначений для всіх бажаючих користувачів.

## Ролі
- Гість (не зареєстрований користувач)
- Користувач (зареєстрована людина)
- Адміністратор (адміністратор сайту)

## Основний функціонал
Застосунок дозволяє купити онлайн чайну продукцію. Сайт дозволяє користувачам переглядати каталог чаю, шукати за назвою або країною походження, фільтрувати товари за типом чаю (зелений, чорний, улун, білий, пуер, трав'яний), способом обробки, ступенем ферментації та смаковими нотами, сортувати за ціною чи популярністю. Також передбачено сторінки країн походження (регіонів), кошик, швидке оформлення замовлення, особистий кабінет із переглядом історії замовлень та адмін-панель для управління асортиментом.


## Особливість проєкту
- При реєстрації кожному користувачу відкривається бонусний рахунок. Номер рахунку співпадає
з номером телефону користувача. При покупці на бонусний рахунок зараховуються бонуси в розмірі двух відсотків від суми покупки. При наступній покупці до 10% суми можна оплатити бонусами. 
- При реєстрації користувач обов'язково вказує свою електронну пошту, на яку надсилається статус його замовлення.
